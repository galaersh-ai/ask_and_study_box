# Конфигурация

В этом каталоге хранятся только несекретные defaults и схемы проверки.

- `defaults.example.yaml` показывает группы параметров, но не фиксирует ещё
  не принятый стек.
- `*.local.yaml` предназначены для конкретной установки и игнорируются Git.
- секреты передаются через переменные окружения или внешний secret store.
- числовые пороги, лимиты, политики и выбор провайдера не зашиваются в код.

Фактический `defaults.yaml` и его схема создаются на PH-00 после утверждения ADR.
