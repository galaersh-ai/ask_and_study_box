# Стратегия размещения тестов

После PH-00 unit-тесты зеркалируют модули из `src/knowledge_box/`, а остальные
уровни группируются по портам, адаптерам и сценариям:

```text
tests/
├── unit/<module>/
├── contract/<port>/
├── integration/<adapter>/
├── acceptance/<scenario>/
└── fixtures/<provider-or-format>/
```

Модуль без тестов не считается готовым. Этот файл не является тестом; прикладные
тесты появятся только после согласования плана и начала PH-00/PH-01.
