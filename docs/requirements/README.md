# Действующие требования

До переноса исходных продуктовых документов этот файл — единственный реестр.

| Документ | Статус | Что задаёт |
|---|---|---|
| `product-baseline.md` | действует | FR, NFR, SEC, OPS, AC и граница MVP |
| корневой `README.md` | действует | краткая цель и навигация |
| `development-plan.md` | для согласования | модули, этапы и критерии готовности |
| `development-rules.md` | для согласования | процесс разработки и проверки |
| `architecture/decisions/README.md` | рабочий реестр | решения и необходимые spikes |

На PH-00 требования уточняются, получают трассировку к модулям и тестам, но
существующие ID не переиспользуются для другого смысла.

Правило актуальности:

- действует только последняя явно отмеченная версия в этом каталоге;
- заменённая версия переносится в `archive/` и содержит ссылку на новую;
- изменение требования обновляет версию, план, критерии приёмки и при
  необходимости ADR;
- обсуждение в чате не заменяет действующий документ после переноса требований.
