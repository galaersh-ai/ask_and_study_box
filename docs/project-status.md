# Состояние проекта Knowledge Box

**Обновлено:** 13 сентября 2026 г.

**Этап:** планирование

**Версия плана:** 0.1

## Принятые ранее продуктовые решения

- MVP — локальная база знаний и Q&A с проверяемыми цитатами.
- Два демо-пакета: синтетическая компания и курс по AI-агентам.
- Предметная схема готовится вне MVP и импортируется пакетом.
- Runtime допускает внешний инференс переносимой модели; подготовительный
  контур может использовать более сильную внешнюю LLM.
- Learning Studio, Assessment и юридический пакет — последующие проекты.
- Evidence, версии, аудит и модульные контракты обязательны.

## Решения этого этапа

- Подготовлен предлагаемый модульный монолит с портами и адаптерами.
- Определены 14 логических модулей MOD-01–MOD-14 и структура тестов по уровням.
- Составлен план PH-00–PH-08 с проверяемым результатом каждого этапа.
- Секреты, несекретные настройки и промпты разведены по разным контурам.
- Зафиксирован Git-flow: ветка `codex/*`, атомарный коммит, проверки, PR,
  независимое ревью, запрет прямой записи в `main`.

## Выполнено

- Созданы план, правила разработки и `AGENTS.md`.
- Добавлены безопасные шаблоны `.env.example`, конфигурации и промпта.
- Добавлены базовые настройки Git, редактора и Python-инструментов.
- Перенесён самодостаточный baseline требований с ID и критериями приёмки.
- После независимого ревью разведены ID этапов PH и модулей MOD, унифицированы
  имена пакетов, контракт промпта, secret scan и bootstrap Git.
- Прикладной код, зависимости приложения и CI не создавались.

- сверка с концепцией Knowledge Box v0.3 и ADR v0.2 из того диалога;

  коммиты и PR;

  кода и назначенных секретов; `git diff --cached --check` прошёл.
- выполнено независимое read-only ревью; выявленные противоречия устранены.

## Ограничения и открытые вопросы

- Архитектурный стиль и инструменты пока предложены, а не утверждены ADR.
- СУБД, поисковые движки, Web UI и очередь заданий не выбраны.
- Пороги качества и целевое оборудование не определены.
- Указанный GitHub compare оказался недоступен без авторизации; правила
  проверены по локальной ветке `codex/m01-m03-fixes` того же репозитория.
- Системный Python 3.12 в PATH отсутствует; встроенный Python 3.12.14 подтвердил
  синтаксис TOML. Установка окружения и парсинг YAML штатными зависимостями
  остаются проверкой PH-00.
- Remote и `main` не созданы: кандидат seed-коммита хранится в bootstrap-ветке
  `codex/project-planning`. После согласования он публикуется как первый `main`
  без PR по единственному исключению из раздела 6.1 регламента.
