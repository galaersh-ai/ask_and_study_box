# Состояние проекта Knowledge Box

**Обновлено:** 14 сентября 2026 г.

**Этап:** планирование

**Версия плана:** 0.6

**Версия требований:** 0.3 (MVP, утверждено), 0.4 черновик (Learning Studio),
0.1 предварительный черновик (Assessment)

## Принятые ранее продуктовые решения

- MVP — локальная база знаний и Q&A с проверяемыми цитатами.
- Два демо-пакета: синтетическая компания и курс по AI-агентам.
- Предметная схема готовится вне MVP и импортируется пакетом.
- Runtime допускает внешний инференс переносимой модели; подготовительный
  контур может использовать более сильную внешнюю LLM.
- Evidence, версии, аудит и модульные контракты обязательны.

## Решения этого этапа

13 сентября 2026 г.:

- Подготовлен предлагаемый модульный монолит с портами и адаптерами.
- Определены 14 логических модулей MOD-01–MOD-14 и структура тестов по уровням.
- Составлен план PH-00–PH-08 с проверяемым результатом каждого этапа.
- Секреты, несекретные настройки и промпты разведены по разным контурам.
- Зафиксирован Git-flow: отдельная ветка, атомарный коммит, проверки, PR,
  независимое ревью, запрет прямой записи в `main`.

14 сентября 2026 г., по ревью требований и плана (решения владельца):

- Learning Studio — вторая очередь сразу после MVP. Assessment, адаптивное
  обучение и учёт прогресса — следующие очереди. Этапы PH-09–PH-12 и модуль
  MOD-15 предложены планом и ADR-010, но ещё не приняты.
- Пользователи — автор и читатели (FR-011, AC-010).
- Роль «преподаватель» переименована в «автор», «ученик» — в «читатель»: платформа нужна не только для учебных курсов.
- Форматы PDF, DOCX, Markdown, XLSX, CSV; файл до 50 МБ по умолчанию.
- Нагрузка: 100–200 документов на стартовый проект, немного одновременных читателей;
  границы фиксируются в ADR-008 на PH-00 (NFR-009).
- Q&A строится по фактам с указанием фрагментов текста (FR-007).
- Ручное удаление ошибочно загруженного документа (FR-012, AC-009). Точная
  семантика предложена в ADR-011, но ещё не принята.
- Только русский язык (NFR-008).
- Эталонный набор готовит агент, проверяет человек (NFR-006).
- MVP использует облачный инференс модели с путём локального развёртывания.
- Ветки Claude — `claude/*`.
- План перестроен по зависимостям: контракт доступа на PH-01, минимальные
  задания на PH-02, минимальный аудит на PH-03, базовое хранилище на PH-00,
  наполнение демо-пакетов на PH-01, сквозной минимум на PH-03, PH-06 разбит
  на три части.
- Требования MVP v0.3 утверждены владельцем продукта.
- Для будущей Learning Studio обязательное содержимое материалов готовится
  заранее и проверяется автором до публикации. Архитектурная граница ADR-010
  и вариант интеграции с OpenMAIC будут выбраны позднее.
- Для расчётов PH-00 используются подтверждённые 50 МБ по умолчанию и 100–200
  документов на стартовый проект. Только дополнительные значения являются
  примером, а не требованиями: жёсткий предел 100 МБ, 20 ГБ исходников с версиями,
  50 ГБ рабочих данных, пороги 80/95% и два ingest-задания на проект. Для
  установки предлагается два задания по умолчанию; четыре — только сценарий
  benchmark для двух одновременно активных проектов.
- Вопросы для самопроверки без баллов и хранения попыток включены в Learning
  Studio отдельным этапом PH-11. Публикация перенесена в PH-12. Оценивание,
  попытки и прогресс остаются за границей второй очереди.
- Assessment включён в план третьей очередью после Learning Studio. PH-13 —
  обязательная точка решения; MOD-16, требования, ADR-012 и этапы PH-14–PH-15
  остаются предварительными до отдельного согласования владельца.

## Ограничения и открытые вопросы

- Архитектурный стиль и инструменты пока предложены, а не утверждены ADR.
- ADR-010–ADR-012 предложены; владелец отложил их выбор.
- ADR-001–ADR-009 перечислены в реестре, но ещё не перенесены отдельными
  самодостаточными файлами; это необходимо сделать в начале PH-00 до создания
  каркаса и выбора технологий.
- СУБД, поисковые движки, Web UI и очередь заданий не выбраны.
- Критерии спорного результата для review не определены (до PH-03).
- Пороги качества и целевое оборудование не определены.
- Срок хранения резервных копий с удалёнными документами не определён.
- Верхний предел размера файла и квоты не утверждены; в плане приведены
  стартовые значения только для расчётов и обсуждения PH-00.
- Системный Python 3.12 в PATH отсутствует; установка окружения и парсинг YAML
  штатными зависимостями остаются проверкой PH-00.
