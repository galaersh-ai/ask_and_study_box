# Реестр архитектурных решений

До реализации должны быть перенесены и уточнены девять решений из концепции:

| ADR | Решение | Текущий статус |
|---|---|---|
| ADR-001 | Граница продукта и MVP | подтверждено концепцией |
| ADR-002 | Предметная схема формируется вне MVP | подтверждено концепцией |
| ADR-003 | Внешний инференс и переносимость на локальные модели | подтверждено концепцией |
| ADR-004 | Универсальное ядро и предметные пакеты | подтверждено концепцией |
| ADR-005 | Гибридный поиск и роль графа | требует spike PH-04 |
| ADR-006 | Evidence и версионность вместо забывания | подтверждено концепцией |
| ADR-007 | Модульность и отдельный юридический проект | подтверждено концепцией |
| ADR-008 | Минимальная топология хранилищ | требует spike PH-04 |
| ADR-009 | Knowledge Core и сценарные модули | предлагается принять на PH-00 |

Новый ADR создаётся только для решения с реальными альтернативами и заметными
последствиями. Параметр конкретной установки относится к конфигурации, а не ADR.
