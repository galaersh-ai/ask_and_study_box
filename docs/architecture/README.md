# Архитектурная документация

Целевой уровень для MVP — arc42 ESSENTIAL. Канонический пакет
`knowledge` реализует архитектурную роль Knowledge Core. Этот каталог содержит только
план состава; черновики появятся на PH-00, а актуализация по реализованной
системе — на PH-08.

Предусмотрены:

1. цели и измеримые quality scenarios;
2. ограничения и граница MVP;
3. C1 System Context;
4. C2 Container с внешними LLM/embedding-провайдерами;
5. C3 Component для модулей Knowledge Core и Q&A;
6. runtime views: ingest, review, retrieval, Q&A и обновление версии;
7. deployment views для внешней и локальной модели;
8. сквозные правила: безопасность, Evidence, версии, кэш, аудит и ошибки;
9. реестр ADR;
10. риски, технический долг и глоссарий.

Диаграммы должны храниться как текстовые исходники с устойчивыми ID элементов.
Один и тот же модуль не получает разные имена в плане, диаграммах и коде.
