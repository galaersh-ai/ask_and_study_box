# Промпты

Промпты — версионируемые проектные артефакты, а не строки в коде.

Целевой путь: `prompts/<module>/<prompt_id>/vN.yaml`. Схема ответа лежит рядом
как `schema-vN.json`; contract-тесты — в
`tests/contract/prompts/<prompt_id>/`, quality-наборы — в
`tests/fixtures/evals/`. Файл промпта не содержит секретов, адресов окружения
и жёсткой привязки к провайдеру.

`manifest.example.yaml` — только шаблон метаданных. Реальные тексты появятся
вместе с соответствующим модулем и его тестами.
