# Knowledge Box

Репозиторий подготовительного этапа коробочной платформы локальных баз знаний.
Сейчас здесь зафиксированы только план, структура, правила разработки и шаблоны
окружения. Прикладной код не создавался.

## Что подтверждено

- MVP принимает документы и структурированные данные, создаёт версионную базу
  знаний и отвечает на вопросы с проверяемыми цитатами.
- Универсальность обеспечивают общее ядро, предметные пакеты и сценарные
  модули, а не одна схема данных или один большой промпт.
- В MVP входят два демонстрационных пакета: синтетическая компания и курс
  по AI-агентам.
- «Студия предметной области», Learning Studio, Assessment и юридический пакет
  не входят в MVP.
- Runtime MVP может использовать внешний инференс моделей, допускающих
  локальное развёртывание. Подготовка схем и синтетических данных может
  использовать более сильную внешнюю модель в отдельном контуре.

## Предлагаемое окружение

- Python 3.12;
- `uv` для окружения, зависимостей и запуска команд;
- `pytest` и `pytest-cov` для тестов;
- `ruff` для форматирования и статического анализа;
- `mypy` для проверки типов;
- `import-linter` для контроля границ модулей.

Версии фиксируются в `uv.lock` на этапе PH-00 после согласования этого плана.
Сейчас зависимости приложения не выбраны и не установлены.

## Следующий шаг

зафиксировать зависимости, настроить локальные проверки и CI. До согласования
PH-00 прикладная разработка не начинается.
